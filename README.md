# folio

面向现代前端开发、UI 设计与数据可视化的跨宿主工作流插件，一套源码原生适配 **Antigravity**、**Claude Code** 与 **Codex**。

## 当前状态

- **阶段**：v1 架构设计与实施规划已定稿（仓库初始化完成，下一步进入插件清单、Skills、工具脚本与安装器的落地实现）。
- **核心设计**：以“最小化、最高性价比、零预装假设（Clean-slate）”为原则，将场景定型与 `DESIGN.md` 契约、组件与 ECharts 5 可视化规范、静态代码门禁以及自适应视觉验收闭环统一进 4 阶段工程流水线。
